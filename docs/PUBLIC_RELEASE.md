# 公开可运行快照说明（2026-10-19）

本目录从冻结 Source.zip 创建，为单独的干净发布工作目录，不带原仓库 Git 历史。原科研目录不变。

公开变更仅为：通用 README；服务与特征默认使用项目内 data；公开说明中将私有服务器和绝对用户目录改为相对目录；去除赛事筛选、身份报名与私有平台交接文档及材料打包脚本；增加第三方归属和本发布审计。未重新训练、未更改数据 CSV、模型文件、逐日预测或指标数值。

`artifacts/evaluation.json` 的 `pipeline_source_sha256` 及 `evidence/training_protocol.json` 保留**原训练时**的冻结哈希。路径文本改写使部分当前源文件哈希不同；不得把旧哈希改成新哈希后冒称重新训练。`evidence/public_release_manifest.json` 将原冻结哈希、现行公开哈希、各修改文件的前后哈希及删除清单分开列示。JSON 中的本地路径元数据已脱敏，原始服务器档案另行保留。

原始上游下载响应不全在此包；便携数据完整性和原始下载审计是两件事。公开 API 的来源清单可读，不能仅据 `complete=true` 就认为该公开包包含全部原始响应。Atlas 导出仍可按分发清单校验。

锁定依赖在原服务器 Python 3.14 虚拟环境中验证；此说明不等于已在所有平台完成全新安装，也不等于 Docker 已通过测试。公开候选验证结果见 `evidence/public_release_validation.json`。
