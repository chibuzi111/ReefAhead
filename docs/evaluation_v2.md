# v2：分歧、漂移与事件单位审计

这是看过v1测试和2026回放后设计的探索性诊断；不是新模型，也不是新的独立测试。v1点预测、区间、训练源和模型文件哈希全部保持不变。

## 展示与人工复核规则

并列显示AI与物理持续性估计，以及包含两者和原v1区间的比较包络。比较包络没有名义覆盖率，不得称为90%预测区间。当前输入超出2003–2019同像素边际范围、模型在DHW≥4判断上分歧、包络跨4、数据过期或参考缺失时提示人工复核；未触发也不表示安全。

原始像素首次上穿保留。将同一示范海域中相邻上穿日期间隔不超过84天的样本合并，仅用于说明相关性与证据量；84天来自DHW记忆窗口，并不等于生物学事件或气候季节。每个代理在最早上穿日检验恰好7/14天前的区域信号。

## 空间与下一次验证

逐站、年份、日历季度和签发日热应激分层结果见 `artifacts/diagnostics_v2/stratified_metrics.csv`。四个像素都参与过拟合，逐站统计不能证明空间泛化。Allen Coral Atlas的局部栖息地几何只能增加地理背景，不能直接给历史每日白化标签。

未来提升需要先冻结方案，再记录真正前瞻的输入发布时间、签发与到期标签；空间验证应留出完整独立海域，并在内层使用滚动时间划分与标签日期隔离。已见的2022–2026数据都只能用于开发与失败分析。

## 复现

运行 `.venv/bin/python scripts/evaluate_v2.py`。该命令读取v1产物，输出v2报告与诊断表，不训练或修改v1。协议与前后哈希核验见 `evidence/diagnostics_v2_protocol.json` 和 `artifacts/evaluation_v2.json`。
