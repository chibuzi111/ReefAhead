# 2026-10-18：依照赛事社区数据源的项目升级

## 结论和范围
资源帖5152是数据源目录，不含统一比赛数据文件、固定切分或评分脚本。珊瑚方向给出NOAA CRW、ERDDAP、Reef Check Malaysia及Allen Coral Atlas。原项目已接入前两者，引用了第三者报告；本次把Atlas真实空间数据与NOAA像素关联，并补充字段契约、现场数据适配和事件单位诊断。原版v1完整归档于releases/v1_20261016，模型和预测值不变。

## 三类数据的正确关联
NOAA是一日一固定卫星像素的海表热压力；Atlas是历史影像提取的静态浅水生境类别；Reef Check是特定站点、深度、日期与方法的实地调查。时间、空间和生态支持范围不同，不能直接按位置拼接成“每日白化真值”。Atlas的Coral/Algae不能拆解为活珊瑚面积，地图精度也不能当作本预测器的准确率。Atlas白化监测与NOAA触发机制有关，不能直接视为完全独立生态验证。

## 原模型与新增诊断
第7天保留物理基线，第14天保留随机森林残差。没有重新训练或重新选型，不用已见测试分数优化参数。新增比较包络包含原校准区间及模型分歧，明确没有覆盖概率保证。超出训练参考范围、阈值分歧、包络跨阈值、旧数据或参考不足触发人工复核；没有触发也不代表安全。

新增探索性评估见docs/evaluation_v2.md。2026区域代理首日的14天预测和复核仍会漏掉，不能把诊断包装成已解决预警。真正提升需要新的独立海域、未来未见事件与现场方法一致的验证；当前版本不宣称保护成效或可靠业务预警。

## 复现与交付
现有冻结模型仍按README启动。空间获取运行scripts/fetch_atlas_context.py，接口读/api/spatial-context与/api/habitat；字段目录读/api/data-catalog，诊断读/api/evaluation-v2。授权现场CSV可用scripts/import_field_observations.py导入独立目录，不改卫星训练数据。全部新增证据与数据在指定远程服务器；用户已决定暂不公开，身份留空、链接待补。

## 调查站关联的实际缺口
已核验RCM公开互动地图的结构：原始地图共328个点，所用仙本那bbox内41个站，但四个现有0.05°像素内为0个。surveyData按年度存储，trend的1月1日是年度桶，不是实测日期，同location趋势还可能跨站重复。因此即使取得网页结构，也不能立即作为逐日或独立白化标签。原地图没有核实到开放再分发许可，原GeoJSON及完整属性仅保留私有核验证据，不进入产品或交付包。当前空间升级降低了地理混淆，尚未完成同点生态验证；下一步需授权站点资料并据此另设独立卫星像素，预先冻结空间与时间验证方案。

上述0/41是按公开点坐标与网格边界严格匹配的结果，未建模定位误差，不代表附近不存在调查。正式试点应确认点位精度、深度及采样空间范围。
