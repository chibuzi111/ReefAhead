# 90 天小规模验证计划

## 问题与研究假设
场景：仙本那附近海域的巡护准备。技术假设是未来第 7 / 14 天 DHW 预测优于预先定义的强基线；可用性假设是简报帮助目标用户更快且正确理解风险与不确定性。不能把技术误差下降等同于减少珊瑚死亡。

## 已完成离线验证与拟开展前瞻验证的区分
离线验证基于真实历史卫星数据；指标见 artifacts/evaluation.json 与逐日预测。以下 90 天计划为拟执行，不是既有成果。若试点开始时气候事件不足，则报告不确定性并延期事件有效性判断，不制造阳性样本。

## 阶段与责任
第 1–15 天：在取得机构同意后招募 5–8 名目标用户；项目负责人负责需求访谈、知情说明、语言和数据条款，生态顾问确认阈值解释与安全边界；确认实际礁点与卫星像素映射，并在收集试点结果前冻结分析方案。
第 16–35 天：影子运行，每日记录数据到达时间、简报生成时间、预测与区间。由生态顾问人工审阅，不直接推送自动“危险”通知。团队保留失败与延迟日志。
第 36–65 天：交叉任务测试。每位参与者分别使用常规 NOAA 信息和本工作台，随机平衡顺序；使用不重复的等难度案例，记录任务时间、正确率、区间理解与信心。具备条件时按既定方案记录水温与珊瑚状态。
第 66–90 天：按事先冻结的分析方案汇总误差、漏报、误报、区间覆盖、工作量与采用意愿，决定继续、修改或停止。公开去标识化结果和局限。

## 采样与终点
技术主终点：第 7 / 14 天 DHW MAE，分别与持久性、季节气候态和持续 HotSpot 物理基线比较；模型与阈值在试点前冻结。
技术次终点：RMSE、阈值事件精确率/召回率、区间覆盖率及宽度、按年份/站点分层表现。相邻日期/像素不视为独立试验，按连续时间块或年度汇总并报告独立事件数量；小样本置信区间只作探索。
用户主终点：无提示完成指定风险解释任务的比例，目标 ≥80%；相对于常规查看方式，中位任务耗时降低 ≥30%（待验证目标）。
其他终点：错误理解区间的比例、专家拒绝简报的理由、数据更新成功率和单位服务成本。5–8 人属于可用性试点，不能外推到全部地区或证明因果生态效应。

## 现场记录
使用 observation-template.csv。每条记录包含日期（UTC）、点位代码、位置、深度、观察方法、观察者匿名代码、抽样总数、白化样本数和sampling_unit（群体/采样点）、照片索引和授权状态。记录物种或生长型时须统一规范。无现场训练标签时不训练“实际白化预测器”，不以缺失观察当作无白化。

## 安全与停止规则
当数据缺失、不连续、连续过期或发生显著输入漂移时，停止将结果用于当期巡护建议，仅提供历史记录和官方数据入口。模型单次异常应触发人工复核；不得自行要求人员出海、潜水或更改保护措施。所有出行与作业遵守当地主管机构安排和安全程序。
发现敏感生态位置泄露、未获授权数据或容易误导的生态结论时立即撤下相关输出并记录纠正。若误差未优于基线，转用基线并报告，不能为维护 AI 叙事忽略结果。

## 可行性、资源与合作状态
数据管道和推理不依赖大模型付费接口或 GPU，可在普通 CPU 上运行。首期仅需要少量目标用户、远程访谈、生态顾问和数据维护。潜在合作对象是当地管理机构、Reef Check Malaysia 或潜店，但截至材料编写日未联系、未签约，不使用其名称暗示背书。90 天日程以伙伴实际同意开始，非比赛日期自动触发。


## 升级后的空间与事件验证
用Atlas空间背景选择实际试点候选，但须由当地人员确认地貌、深度和真实可观察位置；按survey_id保留方法、sampling_unit及分母。将独立海域整体留作空间验证，不能把已经参与拟合的四像素逐站统计称为空间泛化。未来前瞻试验先冻结参数、指标与复核规则，记录输入实际发布时间，再获取未来到期标签；已见2022–2026只作开发和失败分析。按区域相关事件代理报告证据量，但不将代理等同独立生态事件。
